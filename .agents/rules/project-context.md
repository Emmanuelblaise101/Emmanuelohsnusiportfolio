# Emmanuel Ohanusi — Portfolio Website Context

## Project Overview
This is the personal portfolio website for Emmanuel Ohanusi (Emmanuelblaise101), a product designer.

## Tech Stack
- **Framework:** React 19 + Vite 6
- **Styling:** Tailwind CSS v3.4.17
- **Icons:** Lucide React
- **Build tool:** Vite

## Repository
- **GitHub:** https://github.com/Emmanuelblaise101/Emmanuelohsnusiportfolio.git
- **Branch:** main

## Deployment
- **Platform:** Vercel (connected to GitHub — auto-deploys on every push to `main`)
- To update the live site: `git add . && git commit -m "message" && git push`

## Project Structure
- `src/components/` — All page sections (Hero, About, Projects, Blogs, Contact, FAQ, Footer, etc.)
- `src/data/portfolioData.js` — Centralized data/content
- `public/assets/images/` — All image assets
- `public/files/Emmanuel_Ohanusi_CV.html` — CV file

## Key Notes
- `node_modules/` and `dist/` are gitignored — never commit these
- The project uses `npm run dev` for local development
